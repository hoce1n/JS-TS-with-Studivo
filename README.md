# JS-and-Studivo

One JavaScript concept at a time, read against real code in
[Studivo](https://github.com/hoce1n/studivo).

I have started JS deep-dives many times and stopped halfway. This repo is the habit that replaces
that: pick a topic, find it in Studivo, write one file, open it again the next day.

## Everyday loop

1. Pick one JS topic.
2. Search Studivo for it.
3. Copy `template.md` into `topics/`.
4. Write until I can predict what runs and what throws.
