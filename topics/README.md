# Topic studies

Each folder in `topics/` is one JavaScript topic studied against
[Studivo](https://github.com/hoce1n/studivo).

A topic study is not a tutorial and not a dump of MDN. It is a documented answer to:

> I am learning this JS topic. Where does Studivo already use it, and what does that code teach me?

## Workflow

1. Receive or write a conceptual Markdown note for the topic.
2. Search the Studivo repository for related patterns.
3. Compile the findings into this folder using `templates/topic-study-template.md`.
4. Check claims in the personal REPL.
5. Link related foundation notes from `notes/` when they exist.
